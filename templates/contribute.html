Community contributions

Help improve PlayLink.

Found a game you think should be listed? Open the suggestion form, add the game link and details, then submit it. No coding or GitHub account setup is needed beyond signing in.

Before you submit

  • Valid URL: the destination must be public, load successfully, and use HTTP or HTTPS.
  • No duplicates: search the directory and repository issues before suggesting an existing resource.
  • Correct category: choose the best category from data/categories.json.
  • Useful description: write a short, factual summary based on the resource itself.
  • Safety: do not submit malware, deceptive downloads, credential-harvesting pages, or harmful content.

Submit a game link

It's for the non-technical persons

  1. Open the game link submission form.
  2. Sign in to GitHub if prompted.
  3. Enter the game name, its full link, type, category, and a short description.
  4. Submit the issue. A maintainer will check it before adding the game to PlayLink.

Do not share passwords, personal information, downloads, or files. You only need to provide the public game link.

Submit the game link on GitHub

For technical contributors: Edit the catalog and submit a pull request

  1. Fork the PlayLink repository.
  2. Create a focused branch for your change.
  3. Add games to data/games.json or portals and providers to data/websites.json.
  4. Give every resource a stable unique ID, valid canonical URL, category ID, tags, description, and accurate status.
  5. Run python -m pytest, commit the change, and open a pull request against main.

Maintain the existing JSON format. Catalog changes are reviewed before they are merged; submitting an issue does not add or change the live catalog automatically.

Prefer to start with an issue?

Use the resource suggestion form for a new game or website, or the broken-link form for a link that no longer works. Maintainers will review the URL, duplicates, category, description, and safety before merging any follow-up catalog change.
